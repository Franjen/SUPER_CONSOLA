# Procedencia de los archivos

Importados desde `Biblioteca.zip`, proporcionado por el propietario del proyecto.
El código, las imágenes y el ejecutable conservan sus bytes originales.
Los respaldos se movieron a `historial/` para distinguirlos de la aplicación activa.

Se excluyeron `config_igdb.json` (credenciales), `pythonw_ruta.txt` (ruta del equipo)
y `cache/biblioteca.json` (datos locales regenerables). El ZIP original no se publica,
porque incluye esos archivos.

`LA_SUPER_CONSOLA.exe` es el binario original: no se ejecutó, recompiló ni verificó
su comportamiento. Se recomienda iniciar desde el código Python documentado.
Las portadas son recursos aportados en el ZIP; no se ha determinado su licencia.
No se incluyen ROM, BIOS ni emuladores.
